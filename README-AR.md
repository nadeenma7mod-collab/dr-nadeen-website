# Dr Nadeen — Premium Medical v2

## مهم قبل الرفع
هذه نسخة واجهة + لوحة إدارة متصلة بـ Supabase بعد إكمال الإعداد. لا ترفعها قبل تنفيذ خطوات Supabase أدناه.

### 1) إعداد Supabase
1. افتح مشروع Supabase ثم SQL Editor.
2. راجع أن `public.admin_users` ودالة `public.is_site_admin()` وسياسات RLS التي أعددناها سابقًا موجودة.
3. نفّذ محتوى `supabase-v2-migration.sql` مرة واحدة.
4. تأكد أن حساب الدكتورة موجود في Authentication وأن UID الخاص به موجود في `public.admin_users`.
5. لا تشارك كلمة المرور أو Secret/service_role key.

### 2) إعداد الاتصال
افتح `config.js` وضع:
- Project URL من Supabase > Project Settings > API.
- Publishable key الخاص بالمشروع.
المفتاح Publishable يمكن استخدامه بالمتصفح مع RLS. لا تستخدم secret/service_role key مطلقًا.

### 3) الملفات
ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر GitHub repository واستبدل الملفات القديمة. لا ترفع ملف SQL على أنه HTML؛ اتركه كملف مستقل.

### 4) الدخول للوحة الإدارة
بعد ضبط config.js ونشر الموقع، افتح الموقع واضغط «إدارة الموقع». استخدم بريد وكلمة مرور حساب الدكتورة الذي أنشأته في Supabase Authentication. لا يوجد دخول تجريبي.

### 5) بيانات المتابعين والصور
يمكن إدخال صورة الحساب عبر رابط صورة عام وعدد المتابعين يدويًا. لا تدّعي الصفحة أن هذه الأعداد متزامنة تلقائيًا؛ الربط التلقائي يتطلب API رسميًا وصلاحيات كل منصة.

## حدود النسخة
- لا توجد أزرار حجز أو واتساب أو تيليجرام أو تواصل.
- لا يوجد LinkedIn.
- لا توجد مزامنة تلقائية للمتابعين.
- لوحة الإدارة الحالية تدعم الملف الشخصي، الصور، ألوان الهوية، وبيانات الحسابات الأربعة.
- احفظ نسخة احتياطية من ملفات GitHub قبل الاستبدال.
